☁️ Cross-Device Sync
Not connected
Sync daily logs and staff notes across all team devices in real time using Firebase Firestore (free). All devices sharing the same Studio Code stay automatically in sync.

Setup (one time):
1. Go to console.firebase.google.com → Create a project (e.g. "musicbox-internal")
2. Click Firestore Database → Create database → Start in test mode
3. Go to Project Settings (gear icon) → Your apps → Web app → Copy config values below
4. Paste the same config on every device — they'll sync automatically.
