📊 Google Sheets
Not connected
Import a Google Sheet into Spreadsheets and carry on working here. Music Box checks the sheets you imported every few minutes and brings any changes made in Google across on its own.

This connection can only read. The access Music Box asks Google for is spreadsheets.readonly, so nothing in this app can alter a Google sheet — Google refuses the write. Your edits here stay here.

If the same cell was changed in both places, yours is kept and the clash is listed in Spreadsheets for you to settle. Nothing you type is overwritten by a sync.

Set up at console.cloud.google.com: enable the Google Sheets API, then create an OAuth client ID of type Desktop app.
✨ AI Auto-Fill (Step Up Receipts)
Add an Anthropic API key to enable auto-filling the PEP receipt template from a screenshot. Get a key at console.anthropic.com.
📱 RingCentral (Texts & Voicemails)
Not connected
Connect RingCentral to read incoming texts and voicemail transcripts in the dashboard. Create an app at developers.ringcentral.com to get your Client ID and Secret, then generate a JWT token from the developer console. Credentials are stored by the desktop app and are never displayed again.

Microsoft 365 / Outlook
Not connected
Connect one or more Microsoft 365 accounts to view and reply to emails. Each needs an Azure App Registration with Mail.Read and Mail.Send permissions.
☁️ Cross-Device Sync
Not connected
Sync operational data across authorized team devices in real time using Firebase Firestore. Every device must sign in to the same Firebase account and be allowlisted on the studio document.

Setup (one time):
1. Go to console.firebase.google.com → Create a project (e.g. "musicbox-internal")
2. Enable Authentication → Email/Password, create a dedicated sync user, and deploy the included firestore.rules. Never use test mode.
3. Create musicbox/<studio-code> with memberUids: ["the-auth-user-uid"] in the Firebase console.
4. Copy the Web app config below. Optionally enable App Check with a reCAPTCHA v3 site key before enforcing it in Firebase.
☁️ iCloud Drive Backup — No setup needed, Mac only
Manual encrypted backup: this button writes a portable snapshot to iCloud Drive. The app checks for a newer snapshot after login, but it does not continuously synchronize through iCloud. Use Firebase above for live sync.
Local encrypted data has been preserved. Choose which copy to keep; an encrypted recovery snapshot is created before either action.
